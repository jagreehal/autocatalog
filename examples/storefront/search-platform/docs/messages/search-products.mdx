## Overview

`SearchProducts` is handled by the [[service|Search API]]. It runs a full-text search over the **Search Index** and returns a paginated list of matching products. Use this whenever you need to find products across the catalog, rather than fetching a single product by id with [[event|catalog/get-product]].
