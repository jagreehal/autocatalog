## Overview

`OrderPacked` is published by the [[service|Picking Worker]] when an order has been fully picked and packed. The [[service|Warehouse Service]] consumes it to mark the order ready and publish [[event|fulfilment-platform/fulfilment/order-ready-for-shipping]].
