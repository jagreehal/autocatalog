# Refund Policy v3

Any Agent issuing a refund via `issue-refund` MUST:

1. Verify the order is within the 90-day eligibility window
2. Cap the refund at $500 per ticket without human approval
3. Escalate to a human if cumulative refunds to the same customer exceed $1,000 in 30 days
4. Refuse refunds for non-refundable line items (digital goods, gift cards)

Changes to this Policy require Finance sign-off and a 30-day notice window.
