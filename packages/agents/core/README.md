# autocatalog-agents-core

The agent catalog model: entities, validation, cost, audit, discovery, and the
`autocatalog/graph-v1` adapter that joins agents to events and docs.

Used by `autocatalog-agents-cli` and the site; most people won't import it
directly.

Documented at **[jagreehal.github.io/autocatalog](https://jagreehal.github.io/autocatalog)**.

MIT. No licence key, no telemetry.
