# autocatalog-agents-cli

The `ac agents` commands for an agent catalog: validate, impact, cost, audit,
runtime drift, discovery, MCP and `llms.txt`.

```bash
ac agents validate --root .
ac agents impact tool/issue-refund --root .
ac agents mcp --root .
```

It's an optional install. `ac agents` tells you to add it if it's missing.

Documented at **[jagreehal.github.io/autocatalog](https://jagreehal.github.io/autocatalog)**.
